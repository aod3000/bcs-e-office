💡 คำแนะนำ: ไฟล์ขนาดใหญ่จะถูกส่งเข้า Google Drive ของโรงเรียนผ่าน Google Apps Script (GAS) โดยตรง ไม่กินพื้นที่เว็บโฮสติ้ง แนะนำขนาด 50 - 100 MB เพื่อความรวดเร็วในการแปลงไฟล์

💾 สำรองและกู้คืนฐานข้อมูล (Database Backup & Restore)

บันทึกสำรองข้อมูลทั้งหมดในระบบเป็นไฟล์ JSON เก็บไว้ในเครื่อง และสามารถกู้คืนกลับมาได้ตลอดเวลาเพียง 1 คลิก

📦 สำรองฐานข้อมูล (Backup)

ส่งออกข้อมูลผู้ใช้งาน, ข้อมูลห้องเรียน, นักเรียน, สถิติเช็คชื่อ, แบนเนอร์, และการตั้งค่าทั้งหมด

📥 กู้คืนฐานข้อมูล (Restore)

นำเข้าไฟล์สำรอง JSON เพื่อกู้คืนสถานะข้อมูลและโครงสร้างระบบกลับมาเป็นเหมือนเดิม

🔗 ตั้งค่าลิงก์ Google Apps Script (GAS Web App URL)
